# 📊 Tableau de Bord Social & Territorial (Pau / Pyrénées-Atlantiques)

## 📌 Présentation
Projet Data Analytics analysant la répartition des aides sociales (RSA, APL) et les données socio-économiques dans l'agglomération de Pau (64).

## 🛠️ Outils & Méthodes
- **Google Sheets / Excel :** Nettoyage des données, formule `XLOOKUP` pour lier les tables et vérification via Tableau Croisé Dynamique (TCD).
- **Power BI Desktop :** Modélisation en étoile, création de cartes KPI et graphiques interactifs avec filtres.

## 📁 Structure des Données
1. `Communes_64` : Code INSEE, Nom de commune, Population, Revenu médian.
2. `Indicateurs_Sociaux` : Année, Type d'aide (RSA/APL), Nombre d'allocataires, Montant versé.

## 📈 Résultats Clés
- **Allocataires totaux :** 17 200 foyers
- **Budget total versé :** 7 515 k€
